##  Projetos em destaque

###  Painel de Playlist

Projeto desenvolvido utilizando **JavaScript e Tailwind CSS** para trabalhar com informações de uma playlist.

O sistema realiza cálculos como duração total, média de duração das faixas e classificação das músicas.

**Tecnologias:** JavaScript • HTML • Tailwind CSS

---

###  Sistema de Gerenciamento de Obras

Projeto de desenvolvimento web voltado para o **gerenciamento de obras**, desenvolvido em equipe e utilizando tecnologias de front-end e back-end.

O projeto tem como objetivo aplicar na prática conceitos de desenvolvimento de sistemas, organização de código, integração com banco de dados e trabalho colaborativo utilizando Git e GitHub.
